# HelloDesk AI

A production-style customer communication platform supports live chat widget, email inbox with threading, unified inbox, knowledge base, AI-powered summaries and auto-reply drafts, and custom domain support for the knowledge base.

## Repository Structure

```text

|-- hellodesk-client/      # Next.js + TypeScript frontend
|-- hellodesk-server/      # Node.js + TypeScript backend (modular monolith)
|-- docs/PROJECT.md        # What this project is and why
|-- docs/SETUP.md          # Local setup instructions and tech stack
|-- docs/USER_JOURNEY.md   # End-to-end user journey (signup to invite to conversation)
|-- docs/PHASE_1.md        # Phase 1 scope, features, and trade-offs
|-- docs/API.md            # API endpoint reference
|-- architecture/          # Database schema

```
